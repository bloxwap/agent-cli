# #10 Privy server wallet + authorization key integration

Labels: Wallet & Custody, size:L

## Description
Integrate Privy server-side SDK: create/link a server wallet used as the HL agent (API) wallet, register an authorization key (P-256) for the CLI, sign HL L1 actions (EIP-712) through Privy. Authorization private key stored locally (0600) or via env/OS keychain.

## Acceptance criteria
- [ ] Create or link Privy wallet; persist wallet ID + address in config
- [ ] Generate authorization keypair; register as wallet owner/signer
- [ ] Implement Signer interface from hlclient via Privy signTypedData
- [ ] Errors mapped through Privy mapper
- [ ] Integration test against Privy sandbox (skippable in CI w/o secrets)
