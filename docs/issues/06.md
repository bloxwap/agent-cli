# #6 Structured logging (JSON lines, levels, redaction)

Labels: Security & Observability, size:M

## Description
pino-style structured logger writing JSON lines to stderr and a rotating file under `~/.bloxwap/logs/`. Mandatory redaction of keys, signatures, auth tokens. Correlation IDs (`requestId`, `intentId`) propagated through calls.

## Acceptance criteria
- [ ] Log levels configurable via config/env
- [ ] Redaction tests: private keys/auth keys never appear in output
- [ ] File rotation by size/day
- [ ] `requestId` included on every line within a command
