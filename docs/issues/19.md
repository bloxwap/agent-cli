# #19 Deposit status tracking (`status` polling + DEPOSIT_PENDING)

Labels: Funding, size:M

## Description
Poll Relay status and HL clearinghouse balance to determine deposit lifecycle: `awaiting_funds -> pending -> settled | failed | refunded`. While unsettled, trading commands return `DEPOSIT_PENDING` (retryable).

## Acceptance criteria
- [ ] Deposit state machine persisted
- [ ] `status` shows deposit progress
- [ ] Settlement detected via HL balance increase
- [ ] Runner emits `deposit` events
