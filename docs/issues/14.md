# #14 Relay quote client for HyperCore deposit addresses

Labels: Funding, size:M

## Description
Client for Relay API: request quote with `destinationChainId: 1337`, destination currency perps USDC, recipient = user master address, `useDepositAddress: true`; parse deposit address, origin chain/currency options, fees (app fees, relayer fees), min amount, expiry.

- [ ] Typed quote request/response
- [ ] Supports multiple origin chains/tokens
- [ ] Fee breakdown parsed (Relay app fee, gas, relayer)
- [ ] Errors through Relay mapper
- [ ] Fixture tests
