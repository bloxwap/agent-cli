# #4 CLI framework: JSON in / JSON out, global flags, exit codes

Labels: Core CLI, size:M

## Description
Command router (e.g. `commander`/`citty`) where every command accepts args as flags or a JSON payload (`--json '{...}'` or stdin) and writes exactly one JSON document to stdout. Logs go to stderr only. Global flags: `--config`, `--network mainnet|testnet`, `--pretty`. No interactive prompts (except `init` approveAgent step). Uncaught errors are wrapped via the error model.

## Acceptance criteria
- [ ] Every command prints a single JSON object to stdout
- [ ] Exit code 0 on ok, non-zero mapped from error class
- [ ] `--json` and stdin input supported and validated (zod)
- [ ] `agent-cli --help` and `agent-cli schema <command>` emit JSON schemas for inputs/outputs
- [ ] Tests for success, validation error, and uncaught error paths
