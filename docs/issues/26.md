# #26 `run` command: persistent runner process lifecycle

Labels: Persistent Runner, size:L

## Description
Long-lived process: loads config, opens Privy signing session, single-instance lock (pid file), graceful shutdown (SIGINT/SIGTERM), restartable and idempotent (re-running when already running returns existing runner info). Optional `--daemon`.

## Acceptance criteria
- [ ] Single instance enforced via lock/pid file
- [ ] Restart resumes state (deposits, nonces, subscriptions)
- [ ] Graceful shutdown flushes event log
- [ ] `run --detach` and foreground modes
