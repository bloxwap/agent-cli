# #3 Normalized error model and error code catalog

Labels: Error Handling, size:M

## Description
Define `AgentCliError` and the stable output shape `{ ok:false, code, message, retryable, details }`. Create the code catalog: `INSUFFICIENT_MARGIN, POLICY_REJECTED, AGENT_EXPIRED, AGENT_NOT_APPROVED, DEPOSIT_PENDING, NONCE_COLLISION, RATE_LIMIT, INVALID_SIZE, INVALID_PRICE, UNKNOWN_MARKET, ORDER_NOT_FOUND, RUNNER_NOT_RUNNING, CONFIG_INVALID, NETWORK_ERROR, UPSTREAM_ERROR, INTERNAL`. Each code has a fixed `retryable` default and docs.

## Acceptance criteria
- [ ] Typed `ErrorCode` union + `AgentCliError` class
- [ ] `toJSON()` always emits the exact shape; success shape `{ ok:true, data }`
- [ ] `docs/errors.md` lists every code, meaning, retryable, suggested agent action
- [ ] Unit tests for serialization; codes are append-only (test guards removals)
