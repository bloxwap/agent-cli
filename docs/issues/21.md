# #21 Local pre-trade risk limit checks

Labels: Security & Observability, size:M

## Description
Before signing, validate orders against config limits: allowed markets, max order notional, max position notional, max leverage, daily loss cap, max open orders. Violations return `POLICY_REJECTED` with details. Complements Privy policy.

## Acceptance criteria
- [ ] Limit evaluation function with tests for each limit
- [ ] Applied in order/modify/leverage paths
- [ ] Rejections logged to audit trail
