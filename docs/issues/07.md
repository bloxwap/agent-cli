# #7 Hyperliquid client wrapper around @bloxwap/hyperliquid

Labels: Core CLI, size:M

## Description
Thin module wrapping `@bloxwap/hyperliquid` Info/Exchange/Subscription clients for mainnet/testnet, with asset metadata cache (szDecimals, asset ids, max leverage), price/size rounding helpers, and a pluggable signer interface (so Privy can sign).

## Acceptance criteria
- [ ] Factory for Info, Exchange, WS clients per network
- [ ] Meta cache with refresh; lookup by coin name -> asset id
- [ ] `roundSize`/`roundPrice` respecting szDecimals and 5 sig-fig price rules
- [ ] Signer interface abstraction (no raw key required)
- [ ] Tests against recorded fixtures
