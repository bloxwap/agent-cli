# #11 Privy wallet policies: trade-only, never withdraw

Labels: Wallet & Custody, size:M

## Description
Define and attach Privy policies that allow only HL exchange actions (order, cancel, modify, updateLeverage, etc.) and deny withdraw/usdSend/spotSend/transfers and approveAgent. Policy also enforces chain/domain restrictions. Limits from config mirrored where Privy supports them.

## Acceptance criteria
- [ ] Policy JSON versioned in repo (`policies/agent-trade-only.json`)
- [ ] Policy applied on `init`; policy ID stored in config
- [ ] Attempted withdraw returns `POLICY_REJECTED` (tested)
- [ ] `agent-cli status` reports active policy ID/version
