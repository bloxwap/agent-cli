# #9 Retry/backoff policy and nonce management

Labels: Error Handling, size:S

## Description
Shared retry helper honoring `retryable`, exponential backoff with jitter, and HL rate-limit awareness. Monotonic nonce generator (ms timestamp, strictly increasing per signer, persisted high-water mark) to avoid `NONCE_COLLISION` across processes.

## Acceptance criteria
- [ ] Configurable max attempts/backoff
- [ ] Nonce generator strictly increasing even within same ms; persisted across restarts
- [ ] Concurrent-process guard (lock file or runner-only signing)
- [ ] Tests for collisions and backoff
