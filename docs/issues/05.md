# #5 Config file ~/.bloxwap/config.json with schema, migrations and `config` command

Labels: Core CLI, size:M

## Description
Config store holding network, Privy app/wallet IDs, agent address, agent expiry, limits (max notional, max leverage, max order size, daily loss), allowed markets, builder fee settings, API keys refs. Zod schema with versioning/migrations, atomic writes, `0600` perms. Secrets may be referenced via env vars instead of stored in plaintext. `agent-cli config get [key]` / `config set key value` / `config validate`.

## Acceptance criteria
- [ ] Schema + `version` field + migration hook
- [ ] Atomic write (tmp+rename), file mode 0600, dir 0700
- [ ] `config get/set/validate` return JSON; invalid set returns `CONFIG_INVALID`
- [ ] Env var overrides (`BLOXWAP_*`) documented
- [ ] Unit tests incl. corrupt file handling
