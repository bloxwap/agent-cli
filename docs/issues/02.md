# #2 ADR: choose runner command interface (stdin JSON-RPC vs local HTTP vs Unix socket)

Labels: Persistent Runner, size:S

## Description
Decision record comparing stdin JSON-RPC, localhost HTTP and Unix domain socket for talking to `agent-cli run`. Criteria: multi-client access (CLI subcommands must reach a running runner), security (no network exposure), Windows support, simplicity for LLM agents. Recommended default: JSON-RPC 2.0 over a Unix socket at `~/.bloxwap/run.sock` (named pipe on Windows), with `0600` permissions; document the alternative considered.
