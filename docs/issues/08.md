# #8 Map Hyperliquid, Privy and Relay errors to normalized codes

Labels: Error Handling, size:M

## Description
Adapters translating upstream failures (HL order statuses/err strings, HTTP 429, Privy policy denials, Relay quote/status errors, network errors) into catalog codes with `details` preserving upstream payload (redacted).

## Acceptance criteria
- [ ] `mapHyperliquidError`, `mapPrivyError`, `mapRelayError`, `mapNetworkError`
- [ ] Fixture-driven tests for each known HL error string (margin, min size, tick, rate limit, nonce)
- [ ] Unknown errors -> `UPSTREAM_ERROR` with raw message in details
- [ ] Retryable flags correct for 429/network/nonce
