# #17 `fund` command: deposit address, QR, min deposit and fee transparency

Labels: Funding, size:M

## Description
`agent-cli fund [--origin-chain] [--amount]` requests a Relay quote and outputs deposit address, QR, origin chain/token, min deposit, expected received amount on HyperCore (8 decimals), Relay app fees, Relay fees, Hyperliquid builder fee rate, quote expiry, and a `depositId` for polling.

## Acceptance criteria
- [ ] Output JSON includes all fields above
- [ ] Below-minimum amounts rejected with clear code
- [ ] Deposit tracked in local state for status polling
- [ ] Works idempotently (reuses unexpired address)
