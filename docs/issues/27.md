# #27 Runner command interface (per ADR) and client routing

Labels: Persistent Runner, size:L

## Description
Implement the chosen interface (default JSON-RPC over Unix socket). Expose methods for all trading/read commands. CLI subcommands auto-detect the runner and route through it so a single process owns nonces and signing.

## Acceptance criteria
- [ ] Server with JSON-RPC 2.0 framing, errors in normalized shape
- [ ] Methods: status, balance, positions, orders, order, cancel, modify, leverage, config.get, shutdown
- [ ] CLI client fallback to direct mode when runner absent (configurable)
- [ ] Socket permission 0600; tests
