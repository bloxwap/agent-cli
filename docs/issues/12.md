# #12 `init` command: Privy wallet, agent key, one-time approveAgent

Labels: Wallet & Custody, size:L

## Description
Idempotent onboarding: check config, create/link Privy wallet + policy, then produce the `approveAgent` payload (agent address, name, `validUntil` <= 180 days) for the user to sign once with their master wallet. Support: (a) printing an EIP-712 payload / deeplink / QR for external wallet signing, (b) pasting back a signature. Never accept a master private key. Verifies approval via HL info (`extraAgents`). Also sets builder fee approval (`approveBuilderFee`) in the same user flow.

## Acceptance criteria
- [ ] Re-running `init` on configured setup is a no-op returning current state
- [ ] approveAgent payload shown as JSON + QR/deeplink; signature submitted to HL
- [ ] Explicitly rejects any input resembling a private key
- [ ] Agent expiry stored; must be <= 180 days
- [ ] Builder fee approval included and verified
- [ ] Output JSON includes master address, agent address, expiry, policy ID
