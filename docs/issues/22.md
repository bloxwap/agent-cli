# #22 `order` command (limit, market/IOC, reduce-only, TP/SL)

Labels: Trading Commands, size:M

## Description
Thin wrapper: coin, side, size, price/type, tif, reduceOnly, cloid, optional TP/SL triggers. Rounds size/price, applies limits, builder fee, signs via Privy, returns order status (resting/filled/error) normalized.

## Acceptance criteria
- [ ] Supports Gtc/Ioc/Alo and market via slippage-bounded IOC
- [ ] Client order id (cloid) supported for idempotency
- [ ] Invalid size/price -> INVALID_SIZE/INVALID_PRICE
- [ ] Routed through runner when running
